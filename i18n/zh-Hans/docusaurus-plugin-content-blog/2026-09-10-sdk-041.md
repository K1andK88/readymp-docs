`0.4.1` 只包含 bug 修复和性能改进。对外的 SDK API 面没有变化，因此针对 `0.4.0` 构建的模组不需要任何改动，也不需要重新编译。

<!-- truncate -->

## 变更

* **聊天默认开启。** `0.4.0` 默认把它关掉了，结果带来的困惑比好处更多。你仍然可以在 SDK 模组的客户端配置中为自己的服务器关掉它。
* **联机合作中的过场动画卡死。** 击败某些 Boss 后，玩家会卡在过场动画里。已修复。
* **内存紧张时的状态不同步。** 当主机内存不足时，服务器可能与客户端的游戏状态逐渐脱节。已修复。
* **对战模式的防拖延伤害**在启用后毫无作用。现在它会按配置生效。

## 更新

二进制软件包和 Docker 镜像都已发布，两种游戏模式没有变化。请从[安装指南](/wukong-mp/docs/Server/installation)或[快速开始](/wukong-mp/docs/quick-start)获取新版服务器，这两页现在描述的都是 `0.4.1`。

针对 `0.4.0` 构建的模组无需改动，也不用重新编译，可以继续使用。

:::important[服务器与 SDK 模组成对发布]

服务器二进制文件和随它分发的 `WukongMp.Sdk` 模组是一起构建的，因此必须来自同一个发布版本。把 `0.4.0` 的 SDK 模组放到 `0.4.1` 的服务器二进制文件上，会导致服务器在启动时崩溃。

只有当你手动从不同的下载包里拼凑服务器文件夹时，才会碰上这个问题。整包替换（也就是下载包本身给你的东西）就永远不会遇到。无论如何，你自己的模组都不受影响，因为这些都不属于 API 面。

:::
